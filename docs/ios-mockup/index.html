RivetIT for iOS — screen mockups

A one-to-one iOS translation of every screen in the RivetIT Android app: same screens, same order of information, same actions and copy, drawn with native iOS patterns (navigation bar, tab bar, sheets, alerts, segmented controls) in the RivetIT teal brand. Data is the fictional Summit Ridge demo. Each caption names the Android route it mirrors.

Android → iOS component mapping (what “1-to-1” means here)

AndroidiOS
Top app bar (menu · brand · search · alerts · bell)UINavigationBar: leading menu button, brand mark + wordmark, trailing SF Symbols. Detail screens use the standard back chevron with the parent title and an inline title.
Floating bottom nav (5 items)UITabBar with the same five tabs (Home, Tickets, Depts, Assets, Appts); translucent system material, selected tint = RivetIT teal.
Navigation drawerSide menu opened from the leading button (or the same list as a sheet on compact widths). Contents and order are identical to Android.
FAB (new ticket, scan, new appointment)Floating circular/rounded-square button above the tab bar; the same destinations.
Segmented pill (Open/Closed, alerts, appointments)UISegmentedControl.
FilterChip rowsCapsule filter buttons with the same selection model; horizontally scrollable.
ModalBottomSheet (reply, pickers)Sheet with grabber and .medium/.large detents; Cancel left, primary action right; interactive dismiss disabled while a write is in flight.
AlertDialog (resolve, delete)UIAlertController (.alert) with the same copy; destructive actions use the destructive style.
Material text fieldInset rounded field with a small tinted label; same validation messages.
Stepper (hours / minutes)Native stepper treatment with the same increments (5 min).
BiometricPrompt (credentials gate)LocalAuthentication (Face ID / Touch ID); the glyph follows the device. Same “Authentication Required” copy and Authenticate button.
Status / priority colour + textIdentical semantic colours and labels (never colour alone); chips keep the text label.
TypographySF Pro with Dynamic Type text styles (largeTitle/title/headline/body/footnote). Layouts must reflow at accessibility sizes, as the Android 200% pass requires.
MotionSystem spring transitions; honour Reduce Motion. Haptics: UINotificationFeedbackGenerator on confirmed save / failure.
Offline banner, errors, retrySame states and copy as Android: inline banner, “Something went wrong” with Retry, 403 “You don’t have access to this section”.
Role gating (/me permissions)Hide the same items Android hides: tabs, menu entries, New Ticket, reply bar, add buttons.
